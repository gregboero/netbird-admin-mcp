# Security policy

Report vulnerabilities through GitHub's private vulnerability reporting for this repository. Do not include live PATs, passwords or private server addresses in public issues.

Only the latest tagged release is maintained. The NetBird API catalog is pinned to 0.82.0.

Use a dedicated NetBird service account with the least permissions needed. Protect the MCP host, its environment and encrypted response directory. Treat plugin skills as workflow instructions rather than a cryptographic proof that a human approved a mutation.

Please include a minimal reproduction using a mock or disposable instance, the plugin version, Node version, operating system and expected versus observed behavior.
